# INU 지면 패밀리 스킬 (inu-print-family)

인천대학교 산학협력단 산학협력팀에서 쓰는 A4 인쇄용 문서 스킬 5종입니다.
**필요한 스킬만 골라 하나씩 설치하세요.** (zip 하나 = 스킬 하나)

## 1. 내려받기 — 아래 링크를 누르면 바로 다운로드됩니다

| 스킬 | 이럴 때 씁니다 | 다운로드 |
|---|---|---|
| 지면형 보고서 | 한글 간행물처럼 줄이 맞는 A4 결재용 보고서 | [inu-print-report.zip](https://github.com/kirium4u-blip/inu-print-family/raw/main/inu-print-report.zip) |
| 컨설팅형 | 결론 문장 제목 + 근거 도표로 짜는 가로형 검토·건의 보고 | [inu-print-consult.zip](https://github.com/kirium4u-blip/inu-print-family/raw/main/inu-print-consult.zip) |
| 팩트시트 | 교육·사업·행사를 A4 한 장에 담은 배포용 안내 | [inu-print-factsheet.zip](https://github.com/kirium4u-blip/inu-print-family/raw/main/inu-print-factsheet.zip) |
| 성과보고서형 | 큰 숫자·하이라이트·타임라인의 매거진형 성과집 | [inu-print-annual.zip](https://github.com/kirium4u-blip/inu-print-family/raw/main/inu-print-annual.zip) |
| 실습 가이드형 | 체크박스·복사 칸·증상→해결로 따라 하는 실습 자료 | [inu-print-guide.zip](https://github.com/kirium4u-blip/inu-print-family/raw/main/inu-print-guide.zip) |

## 2. 설치하기 (claude.ai)

1. claude.ai 왼쪽 아래 이름 → **설정(Settings)** → **기능(Capabilities)** 으로 갑니다.
2. **코드 실행 및 파일 생성** 기능이 켜져 있는지 확인합니다. (꺼져 있으면 스킬 메뉴가 안 보입니다)
3. **스킬(Skills)** 항목에서 **업로드**를 누르고, 내려받은 zip 파일을 **압축을 풀지 말고 그대로** 올립니다.
4. 스킬 5개가 모두 필요하면 3번을 zip마다 한 번씩, 다섯 번 반복합니다.

## 3. 자주 막히는 지점

- **zip을 풀어서 올리면 안 됩니다.** 받은 zip 그대로 올리세요.
- **여러 스킬을 하나의 zip으로 다시 묶으면 업로드가 거부됩니다.**
- 회사 계정에서 스킬 메뉴 자체가 없다면 조직 관리자 설정에서 막혀 있을 수 있습니다. 담당자(산학협력팀 윤진영)에게 알려 주세요.
- 설치 후에는 새 대화에서 "팩트시트 만들어줘", "지면형 보고서로 정리해줘"처럼 요청하면 해당 스킬이 자동으로 쓰입니다.
